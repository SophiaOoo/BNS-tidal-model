# BNS-tidal-model
The notebook "BNS-tidal-model" is a consolidated version of all my code that runs independently of any external python files. It contains three animations:

1. Stationary reference frame with point mass companion
2. Corotating reference frame with point mass companion
3. Corotating reference frame with tidally perturbed companion

This notebook also contains an explanation of the math behind the model.
